# 09 - 新手導覽頁面 (Guide Page)

## 1. 頁面概述
新手導覽頁面（Guide Page）主要用於向初次使用或需要重新了解 App 功能的用戶，展示核心的選股策略與介面特色。頁面採用全螢幕沉浸式設計，透過 5 個步驟的互動式虛擬卡片，循序漸進地介紹應用程式的核心價值。

## 2. 進入節點 (Entry Points)
目前系統中可以透過以下方式進入導覽頁面：
1. **更多頁面 (More Page)**：用戶可從底部導覽列進入「更多」(`/home/more`)，點擊「新手導覽」清單選項進入。
2. **初次登入/註冊流程**：作為新用戶完成註冊或首次開啟 App 時的 Onboarding 流程（目前實作包含模擬登入邏輯）。

## 3. 導覽步驟說明
本頁面包含 5 個主要教學步驟，可透過左右滑動手勢或點擊下方按鈕切換：

| 步驟 | 標題 | 副標題 | 視覺呈現組件 (Demo) |
|:---:|---|---|---|
| **1** | 個股星級評價 | 找股票不用再看一大堆數字，看星星數就知道 | 展示個股資訊卡片，包含總分星級評分系統與 3 大細項評分項目（挑噴出/回檔、選型態看趨勢、看量找動能）。 |
| **2** | 強勢明星股 | 當今強勢股不用猜，一眼就能看出 | 顯示帶有火焰圖示的強勢股列表，強調帶量突破的股票視覺特徵（搭配脈衝動畫）。 |
| **3** | 獨創！個股強勢線 | 一秒判斷真假強勢股 | 展示 K 線圖與獨創的「強勢線」指標，並附帶下方動態成交量圖表。 |
| **4** | 一鍵選出起漲股 | 4 個起漲關鍵指標，起漲股立即呈現 | 展示「211 強勢股」與「210 起漲股」的專屬篩選按鈕視覺。 |
| **5** | 最新【強勢族群】排行榜 | 類股誰轉強、誰走弱，清清楚楚 | 分別展示「領頭羊類股」(多方) 與「落水狗類股」(空方) 的橫向滑動卡片列，顯示產業排名與子分類。 |

## 4. 互動與操作行為
* **手勢滑動 (Swipe)**：支援螢幕左右滑動，判定滑動距離超過 50px 時切換上一個/下一個導覽步驟。
* **點擊切換**：點擊畫面底部的進度圓點，可直接跳轉至對應步驟。
* **略過 (Skip)**：右上角提供「略過」按鈕，點擊後將結束導覽，並觸發登入狀態跳轉至首頁 (`/`)。
* **下一步 / 開始使用**：底部主要操作按鈕。若處於步驟 1-4，顯示「下一步」；若為最後一個步驟則顯示「開始使用」，點擊後同樣觸發登入狀態並跳轉至首頁。

## 5. 視覺與設計規範
* **背景風格**：深色背景 (`#0a0e14`) 搭配動態光暈與毛玻璃 (Glassmorphism) 擬物化卡片設計。
* **標準色票應用**：
  * 主色調：藍色 `#4A90E2`
  * 強調色：金色 `#D4AF37`
  * 多方/強勢/漲：紅色 `#FE6D73`
  * 空方/弱勢/跌：綠色 `#10B981`
* **圖表套件規範**：此頁面展示的範例圖表（如步驟 3 的強勢線 K 線圖），在實際原生雙平台開發時：
  * **iOS** 需使用 **DGCharts**
  * **Android** 需使用 **MPCharts**

## 6. API 與權限需求
* **純前端展示**：此頁面目前設計為靜態展示，不呼叫外部 API。所有展示用的股票數據、K線數值與產業分類皆為前端 Mock 資料。
* **權限差異**：「VIP版」與「一般版」在此頁面的體驗一致，主要目的是為了引導免費用戶了解 VIP 核心功能並提升訂閱意願。
