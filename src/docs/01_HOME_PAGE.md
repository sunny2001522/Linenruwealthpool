#### ⚠️ 工程師需要實現的功能

**領頭羊計算邏輯**（多方情況下）：

1. **取得數據表**：表 4702290（近120日漲幅）

2. **計算步驟**：
   - 取表中的各欄位
   - 每一欄位：
     - 累加所有股票漲幅數值（A）
     - 計算樣本數（B）
     - 取得領頭羊計算指標：C = A / B
   - 逐欄位生成集合 D（所有 C 的集合）

3. **舉例**：
   - 第一輪計算：取欄位「漲幅(%)119」中所有股票的數值進行加總（A），記錄股票總數（B），計算 C = A ÷ B
   - 第二輪計算：取欄位「漲幅(%)118」重複上述步驟
   - 依此類推，彙整各輪所得的 C 值，形成集合 D

4. **設定領頭羊**：
   - 預設值 = 個股近120天收盤價
   - 領頭羊 = 累乘 (1 + 集合D之第N筆數值/100)（N從0到集合D結束）
