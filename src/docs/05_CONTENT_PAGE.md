## 🎯 頁面概述

**內容頁**提供多元化的學習內容，包含影音、講座、文章、Podcast 四大類型，採用 **YouTube 風格設計**，支援搜尋、排序、收藏等功能。

### 路由資訊
- **路徑**：`/home/content`
- **組件**：`ContentPage`
- **底部導覽圖標**：📄 FileText（內容）
- **是否需要登入**：否（訪客也可瀏覽部分內容）
- **有無底部導覽列**：有

## 🎬 內容卡片設計（YouTube 風格）

### 卡片佈局
- **網格**：
  - 手機：2 欄
  - 平板：3 欄
  - 桌面：4 欄
- **間距**：`gap-4`
- **圓角**：`rounded-lg`

### 卡片結構

#### 1. 縮圖區域
- **比例**：16:9
- **圖片**：內容封面圖
- **疊加元素**（右下角）：
  - **影音/Podcast**：時長標籤（例：「12:34」）
    - 背景：黑色半透明
    - 文字：白色
  - **講座**：價格標籤（例：「NT$ 1,200」）
    - 背景：藍色漸層
    - 文字：白色
  - **文章**：無時長標籤

#### 2. 標題
- **樣式**：粗體
- **行數**：最多顯示 2 行
- **超出**：省略號（`...`）

#### 3. 描述/頻道
- **影音/Podcast**：頻道名稱或描述
- **講座**：講師名稱
- **文章**：作者名稱
- **樣式**：小字，灰色
- **行數**：最多顯示 1 行

#### 4. 日期/時間
- **影音/Podcast/文章**：發布日期（例：「12/31(三)」）
- **講座**：講座時間（例：「12/31(三) 14:00-16:00」）
- **樣式**：小字，灰色

#### 5. 狀態圖標（右上角）

| 狀態 | 圖標 | 說明 | 顏色 |
|------|------|------|------|
| **收藏** | ❤️ | 已收藏 | 紅色實心 |
| **未收藏** | ❤️ | 未收藏 | 灰色空心 |
| **VIP鎖定** | 🔒 | 需要VIP | 金色 |
| **已購買** | ✅ | 已購買講座 | 綠色 |

### 交互行為

#### 點擊卡片
- **影音/Podcast**：
  - 若未鎖定：打開播放器彈窗（`VideoPlayerModal`）
  - 若鎖定：彈出 VIP 升級提示
- **講座**：
  - 若已購買：導航至講座詳情頁（`/course/:id`）
  - 若未購買：彈出購買彈窗
- **文章**：
  - 導航至文章詳情頁（`/article/:id`）

#### 點擊收藏按鈕
- 已收藏：取消收藏，圖標變為灰色空心
- 未收藏：加入收藏，圖標變為紅色實心
- 樂觀更新（即時反饋）

### 未購講座卡片
顯示價格標籤（右下角縮圖上）：
- **文字**：「NT$ 1,200」

#### 彈窗內容

## ⚠️ 工程師需要實現的功能

### 1. 內容 API

#### 獲取內容列表
- **端點**：`GET /api/content/{type}`
- **參數**：
  - `type`：`video`、`course`、`article`、`podcast`
  - `subTab`：子標籤 ID
  - `page`：頁碼
  - `limit`：每頁數量
  - `sort`：排序方式（`latest` 或 `popular`）
  - `search`：搜尋關鍵字（可選）
- **回應**：內容陣列 + 總頁數

#### 獲取內容詳情
- **端點**：`GET /api/content/{type}/:id`
- **回應**：內容完整資訊

### 2. 收藏 API

#### 新增/取消收藏
- **端點**：`POST /api/content/favorites`
- **參數**：
  - `contentId`：內容 ID
  - `type`：內容類型
  - `action`：`add` 或 `remove`
- **回應**：成功訊息

#### 獲取收藏列表
- **端點**：`GET /api/content/favorites`
- **參數**：
  - `type`：內容類型（可選，不傳則返回所有類型）
- **回應**：收藏的內容陣列

### 3. 播放記錄 API

#### 記錄播放進度
- **端點**：`POST /api/content/progress`
- **參數**：
  - `contentId`：內容 ID
  - `currentTime`：當前播放時間（秒）
  - `duration`：總時長（秒）
- **回應**：成功訊息

#### 獲取播放進度
- **端點**：`GET /api/content/progress/:id`
- **回應**：播放進度物件

### 4. 講座購買 API

#### 創建訂單
- **端點**：`POST /api/courses/purchase`
- **參數**：
  - `courseId`：講座 ID
  - `priceType`：`vip` 或 `normal`
- **回應**：訂單 ID + 支付連結

#### 檢查購買狀態
- **端點**：`GET /api/courses/:id/purchased`
- **回應**：`{ isPurchased: boolean }`

### 5. 影音串流

#### 影片播放
- **端點**：`GET /api/content/video/:id/stream`
- **格式**：HLS（`.m3u8`）或 MP4
- **CDN**：建議使用 CDN 加速

#### 音頻播放
- **端點**：`GET /api/content/podcast/:id/stream`
- **格式**：MP3 或 AAC
