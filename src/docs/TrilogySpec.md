# 恩如三部曲（星星）評分邏輯 Spec

此文件定義「選股頁」與「自選股頁」中「恩如三部曲」欄位（星星評分）的計算邏輯。這些計算預計在**後端**處理完畢後，透過 API 直接回傳 `trilogy1`、`trilogy2`、`trilogy3` 三個欄位給前端呈現。

前端根據市場狀態（多方/空方）改變表頭顯示名稱，但底層取得資料的欄位統一為 `trilogy1`、`trilogy2`、`trilogy3`。

---

## 欄位對應與滿分上限
- **① 第一部曲 (`trilogy1`)**：多方顯示「挑噴出/回檔」；空方顯示「挑下殺/反彈」。滿分 2 顆星。
- **② 第二部曲 (`trilogy2`)**：顯示為「看型態」。滿分 2 顆星。
- **③ 第三部曲 (`trilogy3`)**：顯示為「看量找動能」。滿分 2 顆星。

---

## (A) 多方情況下（做多）計算邏輯

### ① 挑噴出/回檔 (`trilogy1`) - 最多給予 2 顆星
此項目由「站上週 20MA」與「強勢週 20MA」兩組條件取**最高星數**。

**條件組一：站上週 20MA**
1. 若該股包含於 Signal ID `5122133` (蓄勢待發) ➜ 獲得 2 顆星
2. 否則，若該股包含於 Signal ID `6086866` (逆轉勝) ➜ 獲得 1 顆星

**條件組二：強勢週 20MA**
1. 若同時滿足以下三個條件 ➜ 獲得 2 顆星：
   - 過去 9 天最低價 > 個股領頭羊(價)
   - 今日最低價與個股領頭羊(價)差距 < 2%
   - 收盤價 > 個股領頭羊(價)
2. 否則，若滿足以下兩個條件 ➜ 獲得 1 顆星：
   - 收盤價 ≥ 個股領頭羊(價)
   - (昨日收盤 ≤ 個股領頭羊(價)) 或 (今日最低價 ≤ 個股領頭羊(價))

> **最終結果：** 取「條件組一」或「條件組二」中較高者作為 `trilogy1` 分數 (0~2分)。

### ② 選型態看趨勢 (`trilogy2`) - 累加制，最多 2 顆星
1. 若該股包含於 Signal ID `6086867` (海闊天空) 或 `6086869` (庸中佼佼) ➜ **加 1 顆星**
2. 若該股包含於 Signal ID `6086884` (一往直前) 或 `103664275` (直道而行) ➜ **再加 1 顆星**

> **最終結果：** 累加後作為 `trilogy2` 分數 (0~2分)。

### ③ 看量找動能 (`trilogy3`) - 累加制，最多 2 顆星
1. 若該股包含於 Signal ID `6086650` (真金烈火) 或 `6086870` (後起新秀) ➜ **加 1 顆星**
2. 若該股包含於 Signal ID `5975178` (金玉其質) 或 `6086872` (前程萬里) ➜ **再加 1 顆星**

> **最終結果：** 累加後作為 `trilogy3` 分數 (0~2分)。
