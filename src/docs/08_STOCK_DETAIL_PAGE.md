## 🎯 頁面概述

**個股詳情頁**提供單一股票的深度資訊，包含最新報價、技術分析（K線）、即時走勢、基本面資料以及營收成長等四大維度，幫助用戶全方位評估個股狀態。

### 路由資訊
- **路徑**：`/stock/:code` （動態路由，帶入股票代號）
- **組件**：`StockDetailPage`
- **是否需要登入**：否（訪客也可查看，但有權限限制）
- **有無底部導覽列**：無（全螢幕顯示，提供返回按鈕）

## 🎨 頂部與價格資訊區

### 1. 頂部 Header
- **左側返回按鈕**：點擊返回上一頁（`navigate(-1)` 或首頁）。
- **中央標題**：顯示股票代碼與名稱，格式為 `(代碼) 名稱`。
- **右側工具列**：
  - **加入自選（愛心）**：
    - 已加入：藍色實心愛心（`#4A90E2`）。
    - 未加入：灰色空心愛心。
    - 點擊開啟「加入自選股」彈窗（`AddToWatchlistModal`）。
  - **搜尋按鈕**：點擊跳轉至全域搜尋頁面。

### 2. 價格資訊卡片
- **狀態標籤**（視資料決定顯示）：上市/上櫃、開盤/收盤等狀態。
- **大字體報價**：顯示當前最新成交價。
- **漲跌點數與幅度**：
  - 數值正（上漲）：顯示「▲」，文字顏色為**台股紅漲（#FE6D73）**。
  - 數值負（下跌）：顯示「▼」，文字顏色為**台股綠跌（#9cffd9）**。
  - 數值平盤：顯示「—」，文字顏色為灰色。

## 📑 分頁內容區塊

### 1️⃣ K線分頁 (KLineTab)

提供技術分析圖表，結合價格與均線，以及對應的成交量。

- **週期選擇器**：提供「日」、「週」、「月」三種 K線週期切換。選中狀態以藍色背景凸顯。
- **當前價格面板**：常駐顯示當前 K線的「開盤、最高、最低、收盤」數值（嚴格遵循紅漲綠跌變色）。
- **均線控制器 (MA)**：
  - **短均 (MA20)**：使用純黃色（`#EAB308`）標示，點擊可開關顯示。
  - **長均 (MA100)**：使用純藍色（`#3B82F6`）標示，點擊可開關顯示。
  - *⚠️ 設計規範警告：此處僅允許使用單色（黃或藍），嚴禁使用黃藍漸層。*
- **K線圖表區**：
  - 支援觸控/游標懸停（Tooltip），點擊特定 K線時，會在其下方顯示該 K線的詳細資訊卡片（包含日期、開高低收、均線值、成交量）。
  - K線本體：收盤 $\ge$ 開盤為紅色（`#FE6D73`），反之為綠色（`#9cffd9`）。
- **成交量區**：
  - 位於 K線圖表下方，柱狀圖顏色同樣依據當日漲跌（紅/綠）進行繪製。

### 2️⃣ 即時分頁 (RealtimeTab)

顯示當日盤中即時走勢。

- **即時價格折線圖**：
  - 以當日開盤價或平盤價作為基準線（黃色虛線）。
  - 價格走勢線：若是處於上漲狀態則使用紅色，下跌狀態則使用綠色。
  - 走勢圖下方帶有同色的半透明填充區塊（Opacity Gradient），增加視覺層次。
- **即時成交量**：顯示在走勢體底部的柱狀圖。

### 3️⃣ 基本資訊分頁 (InfoTab)

以條列清單呈現公司的基本面與屬性資料。

- **顯示欄位**：公司名稱、公司全稱、產業類別、最新季報、最新年報、成立日期、上市日期、市值、董事長、執行長、財務長等。
- **佈局**：左側為灰色欄位標籤，右側靠右對齊顯示具體數據，每列之間使用分隔線區隔。

### 4️⃣ 營收成長分頁 (GrowthTab)

提供公司營收與財務成長性分析圖表（如月營收增減、年增率 YoY 等）。目前為進階資料展示區。

## 🔐 VIP 權限控制

系統嚴格區分「VIP版」與「一般版」權限，在個股頁面有對應的資料觀看限制。

| 功能區塊 | VIP版 | 一般版 |
|---------|--------|--------|
| **即時報價與基礎資訊** | ✅ 完整查看 | ✅ 完整查看 |
| **K線圖表 (日K)** | ✅ 完整查看 | ✅ 完整查看 |
| **K線圖表 (週K/月K)** | ✅ 完整切換與查看 | ⚠️ 整個圖表模糊處理，中央加上**金色鎖頭**與升級提示 |
| **均線分析 (MA20/100)**| ✅ 完整使用 | ⚠️ 鎖定無法勾選 |
| **基本資訊 (Info)** | ✅ 完整查看 | ✅ 完整查看 |
| **營收成長 (Growth)** | ✅ 完整圖表與歷史數據 | ⚠️ 區塊模糊處理，中央加上**金色鎖頭**與升級提示按鈕 |

**鎖定視覺效果（一般版）**：
- 針對受限區域加入 `backdrop-blur-md` 模糊效果與半透明黑色遮罩。
- 正中央放置明顯的「金色鎖頭（`#D4AF37`）」圖標。
- 附加提示文字：「升級 VIP 以查看進階技術分析與營收數據」。
- 放置藍金漸層樣式的「立即升級」按鈕，點擊導航至購買/訂閱頁面。

## ⚠️ 工程師需要實現的功能

### 1. API 與即時報價 (WebSocket)
- **即時報價連線**：需實作 WebSocket 訂閱目標股票代碼，以獲取最新成交價、跳動點數、總量，並即時更新「價格資訊卡片」及「即時分頁」的折線圖。
- **歷史 K線資料 API**：
  - 根據選擇的週期（日、週、月），呼叫對應的 API 獲取歷史開高低收與成交量資料。
  - 需自行或由後端計算 MA20 與 MA100 數值。
- **基本面與營收 API**：呼叫 CMoney 或自有後端 API 獲取公司屬性與歷月營收數據。

### 2. 原生 App 圖表套件整合
- **K線圖與即時圖表套件**：
  - **iOS 平台**：必須使用 `DGCharts` 進行繪製。
  - **Android 平台**：請依「MPCharts」進行繪製。
- **圖表實作要求**：
  - **K線本體 (Candlestick)**：需自定義燭體形狀，嚴格遵循收盤 $\ge$ 開盤為紅（#FE6D73），反之為綠（#9cffd9）。
  - **均線 (MA)**：結合折線圖顯示 MA20（黃）與 MA100（藍）。
  - **動態縮放**：需實作 X軸（日期/時間）與 Y軸（自適應價格區間）的拖曳與縮放互動。
  - **即時圖 (Realtime)**：必須動態計算目前價格位於基準線的上方或下方，並正確套用台股紅綠顏色規則，圖表下方需包含同色的半透明漸層。

### 3. 跨頁面狀態同步
- **自選股狀態 (`watchlistStorage`)**：當用戶在此頁面點擊愛心加入/移除自選股時，需更新全域狀態，確保返回首頁或自選頁時狀態一致。

## 📝 注意事項

### 顏色與設計規範
- ✅ **嚴格遵循台股紅漲綠跌規則**：上漲絕對使用 `#FE6D73` (紅)，下跌絕對使用 `#9cffd9` (綠)。
- ✅ **主色調與強調色**：介面互動元素（Tab 狀態、按鈕）使用藍色 `#4A90E2`；權限鎖定或 VIP 提示使用金色 `#D4AF37`。
- 🚫 **嚴禁使用黃藍漸層**：MA20（黃）與 MA100（藍）的顏色必須是純色分離，不可以在同一個圖標或線上混用漸層。

### 效能優化
- K線數據可能包含數百筆節點，渲染自定義 Tooltip 與 Candlestick 時需注意重繪效能，建議使用 `React.memo` 緩存。
- 切換 Tab 時應保留各 Tab 內圖表的狀態（例如縮放與選擇），避免重新獲取 API 資料。
