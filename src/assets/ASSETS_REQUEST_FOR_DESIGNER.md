## 🎨 設計規範提醒

### 配色方案
| 用途 | 顏色代碼 | 備註 |
|------|---------|------|
| 主色調 | #4A90E2 | 藍色 |
| 強調色 | #D4AF37 | 金色 |
| 上漲 | #FE6D73 | 紅色（台股規則） |
| 下跌 | #9CFFD9 | 綠色（台股規則） |
| 星星漸層 | #FFD700 → #D4AF37 | 亮金到深金 |

### 漸層使用規則
- ✅ **允許**：藍色 (#4A90E2) 到相近藍色 (#3A7BC8 或 #5AA0F2)
- ✅ **允許**：金色漸層 (#FFD700 → #D4AF37)
- ❌ **禁止**：黃藍漸層
- ❌ **禁止**：彩虹漸層或多色漸層

### 檔案格式建議
| 類型 | 格式 | 原因 |
|------|------|------|
| 頭像、圖示 | PNG | 支援透明背景 |
| 照片、橫幅 | JPG | 檔案較小 |
| Logo | PNG | 保持清晰 |
| 向量圖示 | SVG | 可縮放（RD 會轉換） |

## 📤 匯出步驟（Figma）

### 方法 1: 批量匯出（推薦）
1. 選取所有要匯出的圖層
2. 右側面板 → Export
3. 新增三個匯出設定：
   - 1x (預設)
   - 2x (加上 @2x 後綴)
   - 3x (加上 @3x 後綴)
4. 點選「Export 選項」
5. 選擇儲存位置：`/assets/images/`

### 方法 2: 個別匯出
1. 選取單一圖層
2. 右側面板 → Export → +
3. 設定倍率和後綴：
   - 1x → 無後綴
   - 2x → @2x
   - 3x → @3x
4. Export → 儲存

### 方法 3: 使用 Figma 外掛
1. 安裝「Export Kit」或「Figma to React Native」外掛
2. 選取圖層並執行外掛
3. 自動產生多個解析度的圖片

## 🆘 常見問題

### Q: 為什麼需要三個版本？
**A:** 不同裝置有不同螢幕密度：
- 1x：較舊的裝置
- 2x：iPhone 11, 12, 13 標準版
- 3x：iPhone 12 Pro Max, 13 Pro Max

### Q: 星星一定要用圖片嗎？
**A:** 不一定！RD 已經準備了 SVG 版本（`/assets/svg/`），但如果你有更好的設計，可以提供 PNG。

### Q: 可以用 SVG 嗎？
**A:** 可以！但需要 RD 轉換成 React Native 可用的格式。建議先提供 PNG，之後再優化成 SVG。

### Q: 如何測試圖片效果？
**A:** 請 RD 整合後在測試機上查看。或使用 Figma Mirror App 在手機上即時預覽。
